# DSH Desktop

**DeepSeek Harness 的 Windows 桌面版**：双击即用，无需命令行、无需浏览器。

## 特性

- **自包含**：内嵌 Node.js 运行时与 DeepSeek Harness，启动时自动拉起本地服务并打开界面
- **自动更新**：新版本发布后自动检查、静默下载安装并重启，全程无感
- **智能端口**：自动复用已在运行的 DSH 实例，不重复起服务
- **数据不变**：会话、配置仍保存在 `~/.dsh`，与命令行版完全互通

## 安装

1. 到 [Releases](../../releases) 下载最新的 `DSH-Desktop-x.y.z-setup.exe`
2. 双击安装（首次运行若有 SmartScreen 提示，点 **更多信息 → 仍要运行**）
3. 从桌面或开始菜单启动 **DSH Desktop**

## 使用

- 主窗口即 DSH 界面；关闭窗口默认最小化到**系统托盘**
- 托盘菜单：显示/隐藏、在浏览器打开、设置、重启服务器、检查更新、退出
- **设置**（托盘 → 设置）：服务器端口、工作目录、DSH_HOME、自动更新开关

## 更新机制

- 启动 10 秒后及每 4 小时自动检查 GitHub Release 的新版本
- 发现新版本后后台下载，就绪后提示重启安装（可手动"检查更新"）
- 发布新版本：推送 `v*` 标签即触发内置 GitHub Actions 自动构建并发布
